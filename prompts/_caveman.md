OUTPUT STYLE — caveman, the rules inlined here (do not invoke a skill for them). Caveman is for your own
output and agent-to-agent comments (handoffs, review findings, checkpoint notes): no human reads them
live. Write terse: drop articles, filler and pleasantries; fragments are fine; short synonyms; arrows for
causality (X -> Y); one word where one word is enough. Technical terms stay exact.
Human-facing artifacts stay plain prose, never caveman: PRD and issue bodies, PR titles and descriptions,
docs, README, CHANGELOG, commit messages. Exact strings are never compressed: code, commands, errors,
file paths, test names, label names, issue and PR refs, `<!-- harness-… -->` marker lines, the promise.
