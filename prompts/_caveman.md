OUTPUT STYLE — caveman, rules inlined here. For your own output and agent-to-agent comments:
handoffs, review findings, checkpoint notes — no human reads them live. Terse: drop articles, filler, pleasantries;
fragments are fine; short synonyms; arrows for causality (X -> Y); technical terms stay exact.
Human-facing artifacts stay plain prose, never caveman: PRD and issue bodies, PR titles and descriptions,
docs, README, CHANGELOG, commit messages. Exact strings are never compressed: code, commands, errors,
file paths, test names, label names, issue and PR refs, `<!-- harness-… -->` marker lines, the promise.
