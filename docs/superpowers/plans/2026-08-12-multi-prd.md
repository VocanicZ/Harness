# Multi-PRD Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a Harness unit in `prd` mode run several PRD issues — in parallel by default, or strictly sequenced when a PRD declares `## Blocked by #<other PRD>` — instead of silently ignoring every PRD but the first.

**Architecture:** `issuelib.py` grows a `prds` list in `compute_state` (legacy scalar keys retained, derived from the lowest-numbered PRD) and partitions ready-labelled children into per-PRD buckets plus an unparented bucket, attributed via a `## Parent` body section with a `Part of #N` fallback. `dispatch` walks buckets in order, filling slots and spilling. The engine side (`lib.sh`, `drive.sh`, `inject.sh`, `attach.sh`) gains per-PRD orch session names and per-PRD orch worktrees so two orch sessions can run at once without clobbering the shared checkout.

**Tech Stack:** Python 3 (stdlib only, no deps), Bash 4+, tmux, `gh` CLI. Tests are plain-assert Python (`test/test_issuelib.py`) and Bash with `test/helpers.sh` assertions, all driven by `test/run.sh`.

## Global Constraints

- **No new config knob.** Ordering comes from `## Blocked by` on the PRD issue, nothing else.
- **No new dependencies.** `issuelib.py` is stdlib-only; keep it that way.
- **GitHub is the source of truth.** Never persist PRD ordering or attribution to local state.
- **Back-compat is mandatory.** All fleets share `~/.harness/engine` and pick this up on `harness update`. A single-PRD repo with no unparented children must produce byte-identical dispatch output.
- **Legacy scalar keys stay.** `compute_state` keeps returning `prd`, `prd_open`, `prd_reviewed`, `children_exist`, `children_all_closed`, `unblocked`, `open_children`, `total_children`, `paused`, derived from the lowest-numbered PRD. Only `dispatch` and `is_complete` read the new `prds` list.
- **Promise strings are unchanged:** `PLAN DONE`, `PRD DONE`, `DECOMPOSE DONE`, `REVIEW DONE`, `PRD CLOSED`, `ISSUE <n> DONE`. The PRD number travels in the payload field.
- **Run the full suite** with `bash test/run.sh` from the repo root before every commit. Individual Python tests run as `python3 test/test_issuelib.py`.
- Spec: `docs/superpowers/specs/2026-08-12-multi-prd-design.md`.

```python
def parse_parent(body, self_repo):
    """(repo_slug, number) of the PRD this child belongs to, or None when unparented.

    Primary form is a `## Parent` section holding one ref, parsed exactly like `## Blocked by`
    (bare `#N` resolves against self_repo; `owner/repo#N` is honoured; a `None` section means
    deliberately unparented). When no such section exists, falls back to the bare `Part of #N`
    trailer that decompose.md emits today, so pre-upgrade children keep their attribution.
    A `## Blocked by` ref is never harvested — only the two forms above."""
    if not body:
        return None
    m = _PARENT_HEADING.search(body)
    if m:
        rest = body[m.end():]
        nxt = _NEXT_HEADING.search(rest)
        section = rest[:nxt.start()] if nxt else rest
        if _NONE_SECTION.match(section):
            return None
        for r in _ISSUE_REF.finditer(section):
            repo_part, qual_num, bare_num = r.group(1), r.group(2), r.group(3)
            num = qual_num if qual_num is not None else bare_num
            return (repo_part or self_repo, int(num))
        return None
    m = _PART_OF.search(body)
    if m:
        num = m.group(2) if m.group(2) is not None else m.group(3)
        return (m.group(1) or self_repo, int(num))
    return None
```

```python
def compute_state(repo):
    slug = _repo_slug(repo)
    # secure-by-default: drop issues from non-allowed authors up front, so neither PRD
    # selection nor the IMPL claimable filter below can be hijacked by a foreign author.
    issues = _author_filter(_list_issues(slug))
    prd_issues = _prd_list(issues)
    # bug-lane issues live in a separate lane: never claimed by the normal pool and never
    # counted toward unit completion, even when they carry the ready label.
    children = [i for i in issues if L_READY() in i["_labels"] and L_PRD() not in i["_labels"]
                and L_BUG() not in i["_labels"] and L_BUG_TRIAGED() not in i["_labels"]]

    # Partition children by parent PRD. A parent ref that names another repo, or a PRD number
    # that does not exist here, is not attributable — those fall into the unparented bucket
    # rather than vanishing.
    by_parent = {p["number"]: [] for p in prd_issues}
    unparented = []
    for i in children:
        p = parse_parent(i.get("body"), slug)
        if p is not None and _repo_slug(p[0]) == slug and p[1] in by_parent:
            by_parent[p[1]].append(i)
        else:
            unparented.append(i)

    closed_cache = {}

    def _bucket(kids, prd_num):
        all_closed = bool(kids) and all(k["state"].lower() == "closed" for k in kids)
        unblocked = [k["number"] for k in kids
                     if k["state"].lower() == "open"
                     and L_WORKING() not in k["_labels"]
                     and (AUTONOMOUS() or L_BLOCKED() not in k["_labels"])
                     and _is_unblocked(k, slug, closed_cache, prd_num)]
        return all_closed, unblocked

    prds = []
    for p in prd_issues:
        kids = by_parent[p["number"]]
        all_closed, unblocked = _bucket(kids, p["number"])
        prds.append({"number": p["number"],
                     "open": p["state"].lower() == "open",
                     "reviewed": L_REVIEWED() in p["_labels"],
                     # a PRD's own `## Blocked by` is what sequences PRDs; no section = eligible now
                     "eligible": _is_unblocked(p, slug, closed_cache, p["number"]),
                     "children_exist": bool(kids),
                     "children_all_closed": all_closed,
                     "unblocked": unblocked})
    _, unparented_unblocked = _bucket(unparented, None)

    # Legacy scalar keys, derived from the LOWEST-numbered PRD. Kept so `status`, `check` and every
    # existing consumer/test keeps working; only dispatch() and is_complete() read `prds`.
    first = prds[0] if prds else None
    marker = _plan_marker(slug)
    return {"slug": slug, "has_plan": _has_plan(slug),
            "plan_marker_matches": marker is not None and marker.get("spec_hash") == _spec_hash(),
            "prds": prds,
            "unparented_unblocked": unparented_unblocked,
            "open_unparented": sum(1 for i in unparented if i["state"].lower() == "open"),
            "prd": first["number"] if first else None,
            "prd_open": bool(first) and first["open"],
            "prd_reviewed": bool(first) and first["reviewed"],
            "children_exist": bool(children),
            "children_all_closed": bool(children) and all(i["state"].lower() == "closed" for i in children),
            "unblocked": unparented_unblocked + [n for p in prds for n in p["unblocked"]],
            "open_children": sum(1 for i in children if i["state"].lower() == "open"),
            "total_children": len(children),
            "paused": sum(1 for i in children if i["state"].lower() == "open" and L_PAUSED() in i["_labels"])}
```

```python
def dispatch(repo, free_slots, allow_orchestration, busy_prds=()):
    s = compute_state(repo); a = _allowed(MODE()); out = []
    prds = s["prds"]; busy = set(busy_prds); slots = max(0, free_slots)
    if allow_orchestration:
        # Fire a fresh PLAN only with no live PLAN.md AND (no completion marker OR the spec content
        # changed since that marker). A finished plan archives PLAN.md and writes a spec-keyed marker,
        # so without the marker check PLAN would re-fire every poll once the doc is gone.
        if a["plan"] and not prds and not s["has_plan"] and not s["plan_marker_matches"]:
            return [("PLAN", "-", "PLAN DONE")]
        if a["prd"] and s["has_plan"] and not prds:
            return [("PRD", "-", "PRD DONE")]
    # A PRD sequenced behind another via `## Blocked by` contributes nothing — no decompose, no
    # impl, no review — until its blocker closes. No blockers means eligible immediately, which is
    # what makes independent PRDs run in parallel.
    eligible = [p for p in prds if p["eligible"]]
    # DECOMPOSE/REVIEW/CLOSE_PRD are gated PER PRD (via `busy`) rather than by the unit-wide
    # `allow_orchestration`. That unit-wide flag is set only when NO session is live anywhere in
    # the unit, so leaving these under it would mean PRD #2 could never decompose while PRD #1 had
    # a single impl session running — silently re-serializing PRDs authored to run in parallel.
    # PLAN/PRD stay under `allow_orchestration`: they are unit-level and must not race anything.
    if a["decompose"]:
        for p in eligible:
            if p["open"] and not p["children_exist"] and p["number"] not in busy:
                return [("DECOMPOSE", str(p["number"]), "DECOMPOSE DONE")]
    # Slots: unparented bucket (human injections) first, then eligible PRDs ascending, each
    # spilling into the next only once it has no unblocked work left.
    for num in s["unparented_unblocked"][:slots]:
        out.append(("IMPL", str(num), f"ISSUE {num} DONE"))
    for p in eligible:
        if len(out) >= slots: break
        for num in p["unblocked"][:slots - len(out)]:
            out.append(("IMPL", str(num), f"ISSUE {num} DONE"))
    # REVIEW/CLOSE_PRD gate on remaining CAPACITY, not on `not out` as the single-PRD version did:
    # with several PRDs, one PRD's impl work must not suppress another's review indefinitely.
    #   • REVIEW signs off — it applies the reviewed label (and may file gap issues). Gated on
    #     NOT-yet-reviewed so a reviewed-but-still-open PRD doesn't spawn an endless run of fresh
    #     review sessions (each one a live orch session).
    #   • CLOSE_PRD is the mechanical close, done by the ENGINE (drive.sh) via a single idempotent
    #     `gh issue close`, retried every poll — so a signed-off PRD always closes even if the
    #     review agent's own gh call was dropped by a rate limit.
    if a["review"]:
        for p in eligible:
            if len(out) >= slots: break
            if p["number"] in busy or not p["open"] or not p["children_all_closed"]:
                continue
            if not p["reviewed"]:
                out.append(("REVIEW", str(p["number"]), "REVIEW DONE"))
            else:
                out.append(("CLOSE_PRD", str(p["number"]), "PRD CLOSED"))
    return out
```

```python
def is_complete(s):
    if MODE() == "issue-only":
        return s["children_exist"] and s["open_children"] == 0 and len(s["unblocked"]) == 0
    # A CLOSED PRD means that PRD is done. The reviewed label is the sign-off SIGNAL that lets the

    # (injected) child is still open, which is what stops a late injection being stranded.
    prds = s["prds"]
    return bool(prds) and all(not p["open"] for p in prds) and s.get("open_unparented", 0) == 0
```

```bash
# sweep_orphan_orch_worktrees — crash/new-machine recovery for the per-PRD DECOMPOSE/REVIEW
# worktrees, the direct analogue of sweep_orphan_bug_worktrees. An engine killed mid-orch leaves
# orch-<slug>-p<n> on disk with no session; without this the next `worktree add -B agent/orch-<n>`

sweep_orphan_orch_worktrees(){ shopt -s nullglob; local wd prd u san co
```

**Spec coverage.** Every spec section maps to a task: attribution → 1; `prds` list and legacy scalars → 2; buckets and unparented → 3; PRD eligibility → 4; dispatch ordering, spill, REVIEW capacity gate, back-compat guard → 5; `--busy-prds` and `allow_orch` narrowing → 6; completion → 7; goal strings → 8; session names, `team_sessions`, `orch_worktree` → 9; `spawn_orch` split, `reap_orch`, `finalize_unit` → 10; crash recovery → 11; `inject.sh` / `attach.sh` → 12; prompts → 13; rollout docs → 14.

**Type consistency.** `parse_parent` returns `(repo, int) | None` and is consumed only in `compute_state`'s partition loop. PRD dicts use the same seven keys everywhere — `number`, `open`, `reviewed`, `eligible`, `children_exist`, `children_all_closed`, `unblocked` — in `compute_state` (Task 2), the `prd()` test helper (Task 5), and every reader (Tasks 5–8). `busy_prds` is a tuple/set of `int` throughout; `busy_prds_for` emits a comma-separated string that the CLI parses back to ints. Session names come from `sess_orch <unit> <prd>` in all four callers.

**Known behaviour changes** (intended, each covered by a test):

1. DECOMPOSE/REVIEW/CLOSE_PRD no longer gate on the unit-wide `allow_orchestration`; they gate on `--busy-prds` plus capacity. Without this the narrowing is inert — `allow_orch` is 1 only when no session is live, so the busy set would always be empty. Updates one pre-existing assertion (`test_issuelib.py:714`), handled in Task 5 Step 4.
2. REVIEW's outer guard: `not out` → `len(out) < slots`.
3. `is_complete` gains the open-unparented-children clause.
4. Unparented children no longer gate any PRD's `children_all_closed`.
5. Orch session names gain a `-p<n>` suffix, so `attach.sh` and `inject.sh` change with them.

**Deliberate non-goal.** Nothing here detects PRD dependency cycles; a cyclic `## Blocked by` set simply never becomes eligible and no PRD in it is dispatched. That matches the existing `decompose.md` scope guard, which leaves cross-repo cycles to `agent-blocked` escalation.
