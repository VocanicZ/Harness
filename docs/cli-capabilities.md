# Agent CLI capabilities

What each agent CLI in PRD #189 offers Harness, checked 2026-10-27. `docs/plans/2026-10-24-multi-cli.md` builds one adapter per CLI from these rows, and an adapter may encode only what a row here cites.

**How to read a row.**
- Every row cites its source: an official doc page, an upstream source file pinned to the version checked, a file in this repo (`scripts/lib.sh:823`), or `local:` plus a command run read-only on the fleet host on 2026-10-27.
- **UNVERIFIED** means the value comes from source or docs but has not been seen on a real pane or file. The CLI's task must confirm it with a fixture in `test/fixtures/cli/<cli>/` and change the row's source to that fixture.
- **MISSING** means the CLI has no such capability. The row names the Harness-side substitute the adapter implements instead.
- Upstream source paths are abbreviated per section; each section says what its prefix expands to.
- `copilot` and `cursor-agent` are closed source. Their TUI strings come from the published package or the docs, and are confirmed only by their fixtures.

## Findings that change Harness code

These are defects in what Harness did, found while filling the rows. Task 1 of the plan (#188) fixed them; each is a cell of `test/test_cli_matrix.sh`.

1. **`agy` trust is written to the wrong file.** `_trust_agy_config` (`scripts/lib.sh:200-226`) writes `~/.gemini/trustedFolders.json`, which is Gemini CLI's file. `agy` 1.1.27 reads `trustedWorkspaces` in `~/.gemini/antigravity-cli/settings.json`; the binary contains no `trustedFolders` string. A fresh `agy` worktree stops on the trust dialog. **Fixed (#188):** `agy_trust` (`scripts/cli/agy.sh`) writes `trustedWorkspaces`; matrix cell `trust-pre-accepted`.
2. **The `agy` trust dialog matches the `agy` idle regex.** Its selected option renders as `> Yes, I trust this folder` at column 0, which `^(│ *)?>( |$)` (`scripts/supervise.sh:78`) and the unanchored `'❯|>'` (`scripts/lib.sh:840`, `scripts/lib.sh:872`) both match, so supervise would type a nudge into the dialog. **Fixed (#188):** `cli_dialog_re` names the dialog (`test/fixtures/cli/agy/trust.txt`), and a pane it owns is never a prompt; matrix cell `trust-dialog-is-not-prompt`.
3. **`agy` does expose usage windows.** `agy -p "/usage" --output-format json` returns the 5-hour and weekly buckets per model group without running a turn, contrary to `scripts/usage.sh:50-52`. **Fixed (#188):** `agy_limit_usage`; matrix cell `usage-windows`.
4. **`agy` token usage is not in its transcript JSONL.** It is protobuf in `~/.gemini/antigravity-cli/conversations/<id>.db`; `scripts/stats.py` reads only `claude` JSONL. **Fixed (#188):** `scripts/cli/agy_usage.py` decodes it and `session_end` events carry it; matrix cells `usage-from-transcript`, `stats-session-end-usage`. (agy 1.4.8's `brain/<id>/.system_generated/logs/transcript.jsonl` now also carries per-step token counts, but no model.)
5. **`claude`'s busy hint may be hidden by Harness's own status line.** The docs say a custom `statusLine` hides `esc to interrupt` in the footer, and `ensure_usage_statusline` installs one in every `claude` worktree. The fixture must show whether the spinner line still carries it. **Confirmed and fixed (#188):** with the status line set, a turn shows only `✻ Puttering… (1s · ↓ 38 tokens · thinking)` (`test/fixtures/cli/claude/busy-spinner.txt`), so the #115 watchdog read a running turn as idle; `claude_busy_re` keys on the spinner's `… (<timer> ·` shape. Matrix cell `busy-is-busy`.
6. **The `harness-ralph` Stop hook ended every `agy` loop after one turn.** It looked for the promise in every transcript row with content, and agy 1.4.8 logs tool output (a file read, a shell result) as `source: MODEL`, `type: GENERIC`; the task file names the promise, so the agent reading it ended the loop. **Fixed (#188):** only `PLANNER_RESPONSE` rows count (`test/fixtures/cli/agy/hook-transcript.jsonl`, `test/test_agy.sh` Case E). Seen on the host: a 3-iteration loop now runs 3 turns.
